# 迭代记录索引

本目录按时间线记录项目的关键迭代过程,包括每次重要讨论、决策和取舍。

## 为什么记录迭代

1. **避免重复纠结** — 几个月后回来,能快速想起"为什么当初这么决定"
2. **传承决策上下文** — 决策结果在主文档,决策理由在迭代记录
3. **沉淀产品思考** — 把"取舍"显式化,而不是只留下最终结果

## 命名规范

文件名格式: `YYYY-MM-DD-主题.md`

每个迭代记录包含以下章节:
- **时间** — 迭代发生的日期
- **起点** — 开始迭代时的状态和要解决的问题
- **关键讨论** — 讨论过程中的核心问题和选项
- **决策与取舍** — 每个决策的理由和放弃了什么
- **产出** — 这次迭代产出的文档/规则/调整
- **后续待办** — 留给下一次迭代的问题
